# Statische RGB565-Vorschau des Bibliotheksmotivs

Diese erste Studie zeigt das [Bibliotheks-Aquarell](../concepts/illustrationen/02-aquarell-bibliothek.png) in 466 × 466 Pixeln. Sie lässt sich aus dem Projektstamm mit `bash display/amoled/preview.sh` erneut erzeugen.

Der Firmware-Prototyp verwendet das [interaktive Alter Ego der Himmelsgravur](../alter-ego/README.md).
